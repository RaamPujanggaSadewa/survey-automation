# Specs

Two kinds of AI-generated spec live here, both plain `.gs` files so they can
be pushed straight into the Apps Script project.

## Form specs: `<case-name>.spec.gs`

Generated from a case file in `cases/`. Defines `SURVEY_SPEC`, which
`apps-script/Code.gs` reads to build the Google Form. There's no fixed set
of questions or count — the AI decides the mix of question types per case
based on the condition and goal described in the matching case file.

`caseName` must match the case's file name (without `.md`) — it's how the
created form's ID gets stored for the responses step later.

```js
const SURVEY_SPEC = {
  caseName: "case-name",
  title: "Form title",
  description: "Shown at the top of the form.",
  questions: [
    { type: "TEXT", title: "Short answer question", required: true },
    { type: "PARAGRAPH_TEXT", title: "Long answer question", required: false },
    {
      type: "MULTIPLE_CHOICE",
      title: "Single-select question",
      choices: ["Option A", "Option B", "Option C"],
      required: true
    },
    {
      type: "CHECKBOX",
      title: "Multi-select question",
      choices: ["Option A", "Option B", "Option C"]
    },
    {
      type: "LIST",
      title: "Dropdown question",
      choices: ["Option A", "Option B"]
    },
    {
      type: "SCALE",
      title: "Rating question",
      lower: 1,
      upper: 5,
      lowerLabel: "Not at all",
      upperLabel: "Extremely"
    }
  ]
};
```

Supported `type` values match what `apps-script/Code.gs` implements:
`TEXT`, `PARAGRAPH_TEXT`, `MULTIPLE_CHOICE`, `CHECKBOX`, `LIST`, `SCALE`.

## Slides specs: `<case-name>.slides.gs`

Generated by the AI from `responses/<case-name>.json` (see `responses/README.md`)
once the survey is done. Defines `SLIDES_SPEC`, which `apps-script/Slides.gs`
reads to build a Google Slides deck: a title slide plus one
title-and-body slide per section. There's no fixed structure — the AI
decides how many sections and what they cover based on what the responses
actually show.

```js
const SLIDES_SPEC = {
  title: "Deck title",
  subtitle: "Shown under the title on the first slide.",
  sections: [
    {
      heading: "Section heading",
      bullets: [
        "First finding or point.",
        "Second finding or point."
      ]
    }
  ]
};
```
